## Sobre as datas
As datas de `projeto-01`, `projeto-02` e `projeto-04` vêm diretamente dos timestamps internos dos arquivos (preservados no `.zip` original, gerados automaticamente ao salvar cada arquivo) — a mesma lógica confiável usada nos repositórios anteriores. É possível ver, por exemplo, que o projeto de RPG foi refatorado para o padrão MVC exatamente entre 04/04 e 19/04/2023: os arquivos de `models/` têm data mais recente que o resto do projeto.
