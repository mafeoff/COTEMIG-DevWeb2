# Web Development II — DEVWEB2 3C2 2023

Projects from the **Web Development II** course (DEVWEB2), class 3C2, COTEMIG — 2023. The repository combines PHP + MySQL (traditional back-end development) with a TypeScript/Node.js exercise.

## Projects (in chronological order)

| Folder | Description | Dates |
|---|---|---|
| [`projeto-01-diagrama-uml/`](projeto-01-diagrama-uml/) | UML class diagram (Character/Battle) | 03/17/2023 |
| [`projeto-02-calculadora-php-mysql/`](projeto-02-calculadora-php-mysql/) | PHP calculator that stores operations in MySQL | 03/16–03/17/2023 |
| [`projeto-04-rpg-mvc/`](projeto-04-rpg-mvc/) | PHP RPG game evolving from direct code to the MVC pattern | 04/04 → 04/19/2023 |
| [`projeto-typescript-municipios/`](projeto-typescript-municipios/) | Reading municipality data using TypeScript classes | 07/07/2023 |

## About the Dates

The dates for `projeto-01`, `projeto-02`, and `projeto-04` come directly from the internal timestamps of the files, preserved in the original `.zip` archive and automatically generated when each file was saved. This is the same reliable method used for the previous repositories. For example, the RPG project can be seen evolving to the MVC pattern specifically between April 4 and April 19, 2023, as the files in `models/` have more recent timestamps than the rest of the project.
